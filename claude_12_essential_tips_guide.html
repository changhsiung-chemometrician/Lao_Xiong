核心導讀 [00:00:00]：Claude 近期的功能更新幅度極大，許多幾個月前的教學都已過時。本指南依據 Anthropic 官方最新說明文件，將 12 個立即可用的實戰技巧分為初級（基礎設定與額度管理）、中級（深度脈絡與外部工具串接）與高級（瀏覽器自動化、排程與無程式碼開發）三個階段，並標註每個功能的設定路徑、應用範例、需避免的錯誤以及適用方案。
初級（技巧 1 – 4）

只需設定一次的基礎架構、提問習慣與額度控管

1. 註冊 Email 規劃與資料匯出意識

所有方案適用 [00:01:14]
功能說明：Claude 帳號綁定的 Email 無法直接更改。所有對話紀錄、記憶（Memory）、Projects、Skills 與已連結的應用程式都與該帳號深度綁定；若日後更換帳號並刪除舊帳號，所有資產都會一併消失。
操作建議：註冊前確認使用個人永久持有的信箱。若確實需要更換帳號，務必先依照官方說明匯出備份資料。
避免錯誤：切勿使用未來可能失效的公司信箱或學校信箱註冊主力帳號。

2. 30 秒全域個人偏好設定與三個高效提問習慣

所有方案適用 [00:02:00]
設定路徑：點擊左下角名字縮寫 → Settings → Instructions for Claude。
設定內容（三要素）：寫明「你是誰」、「你主要用 Claude 做什麼」以及「偏好的回答風格」（例如：一律使用繁體中文、金額以美金顯示、回答精簡並先列重點）。
三個關鍵提問習慣 [00:02:36]：
  • 提供真實具體背景：與其泛問行銷點子，不如具體說明「經營手工蠟燭網店、每月預算 100 美金、沒時間每天發文」。
  • 直接提供原始素材：不要只用文字描述，直接上傳 PDF、截圖、試算表或手寫筆記照片，讓 Claude 讀取完整細節並節省打字時間。
  • 任務前後的雙向確認：執行大型任務前加上「開始之前有任何需要知道的先問我」，避免 AI 自行猜測；完成後再請它對照原始需求檢查是否有遺漏。

3. 跨平台記憶遷移（Memory Import）、記憶管理與語音設定

免費可用 / 歷史搜尋限付費 [00:03:25]
設定路徑：Settings → Memory → 點擊 Start import。
運作方式：將 Claude 提供的提示詞貼到原本使用的 AI（如 ChatGPT），再把對方整理出的個人背景複製貼回 Claude。同時開啟 Generate memory from chats 讓 Claude 在日常對話中持續學習。
進階應用與備份 [00:04:11]：
  • 回憶搜尋（付費方案）：可直接要求 Claude 找出過去討論過特定主題（例如定價規劃）的對話，無需手動往上翻找。
  • 定期備份記憶：要求 Claude「把你對我的記憶一字不漏地寫出來」並另存檔案。
  • 語音輸入語言：前往 Settings → General → Voice → Language 確認支援語言（非英語系目前屬測試階段）。
注意細節：Claude 的記憶系統刻意設計為以「工作相關主題」為主，部分純私人生活細節在匯入時可能會被過濾，建議匯入後手動檢視並增刪。

4. 模型分級與 Effort（思考強度）雙重節流策略

Haiku/Sonnet 免費 · Opus/Fable 付費 [00:04:47]
四大模型定位：
  • Haiku：適合快速問答、重點摘要與清單分類。
  • Sonnet：日常預設主力，適合一般寫作與分析。
  • Opus（付費）：適合深度研究與高難度邏輯推理。
  • Fable（付費）：適合超大型、長週期專案，會自主規劃步驟並自我檢查成果。
省額度黃金法則 [00:05:19]：善用模型選單旁的 Effort（思考強度）控制項。一律先從 Sonnet + 預設 Effort 開始；簡單整理改用 Haiku + 低 Effort；僅在答案深度不足時才升級至 Opus 或調高 Effort。
避免錯誤：切勿只為了修改錯字或潤飾一句話就開啟 Fable 搭配高 Effort，這會極快耗盡使用額度。
中級（技巧 5 – 8）

深度資訊檢索、工作區脈絡累積與外部應用串接

5. 精準選擇三種資訊獲取模式（搜尋、延伸思考、Research）

Research 限付費方案 [00:06:10]
三種模式比較：
  • 網頁搜尋（Web Search）：適合查詢 1～2 次搜尋即可確認的即時事實。
  • 延伸思考（Extended Thinking）：不需連網但需要嚴密推演的任務（如數學計算、專案規劃、複雜決策），由 Effort 控制思考深度。
  • 深度研究（Research，付費）：點擊對話框 + 號啟用。會執行 5 次以上多輪檢索，耗時約 1～3 分鐘，產出附帶完整引用來源的分析報告。
跨應用研究技巧 [00:07:06]：在網頁版或桌面版啟動 Research 時，可同步抓取已連結的 Gmail 與 Google Calendar 內部資料（手機版僅限搜尋公開網路）。由於 Research 消耗額度較快，建議用於「明確定義需求、手動整理需耗時一整個下午」的複雜調研（例如比較跨國網店三種最低成本收款方案的手續費、設定步驟與風險）。

6. Projects 專屬工作區與知識庫建置

免費方案上限 5 個 [00:07:27]
最新功能更新：打破過去 Projects 無法讀取全域記憶的限制，現在 Projects 會同時結合「帳號全域記憶」與「專案獨立記憶」（若需完全隔離客戶資料，可在專案頁面關閉 Use account memory）。
最佳實踐：為每個客戶、課程或副業建立獨立 Project，上傳價目表、品牌指南、優質作品範例，或直接貼上 Google Drive 文件連結。專案專屬指示（Instructions）可直接開新對話請 Claude 透過提問幫你撰寫。

7. 將重複性工作流程封裝為 Skills（專屬食譜）

需開啟程式執行權限 [00:08:37]
核心概念：Project 存放的是「背景資料」，而 Skill 存放的是「標準作業方法（SOP）」。不需要寫程式即可建立。
建立與管理路徑：先於設定開啟 Code execution and file creation；接著在對話中描述任務步驟、上傳輸出模板並回答 Claude 的問題，即可自動打包為 Skill，並於 Customize → Skills 進行管理與迭代測試。
適用場景：當你第二次複製貼上同一段長指令時就該做成 Skill，例如：固定品牌語氣的商品文案撰寫、特定術語表的繁中翻譯、依據價目表自動回覆客訴與詢價。
安全提醒：切勿隨意安裝網路上來源不明的第三方 Skill，安裝前務必檢視其內部檔案，因為 Skill 內可能包含可執行程式碼。

8. 外部服務連接器（Connectors）與 Excel 專屬外掛

基礎連接器免費 · Excel 外掛付費 [00:09:53]
設定路徑：對話框點擊 + → Connectors（或前往 Customize → Connectors 瀏覽 Slack、Notion 等完整目錄，僅需連接每天高頻使用的 2～3 個工具即可）。
Google 生態系實戰能力：
  • Gmail：已從單純搜尋草擬升級為可直接寄信、回信與轉寄（預設寄出前均會暫停請求確認）。
  • Google Calendar：可查詢所有與會者的共同空檔、新增移動行程並發送會議邀請。
  • Google Drive：可搜尋閱讀 Docs、Sheets、Slides 與 PDF，並直接將生成檔案存入雲端硬碟。
Claude for Excel（付費）[00:11:03]：於微軟外掛商店搜尋 Claude for Microsoft 365 安裝。可解釋複雜儲存格公式邏輯、排查 #REF! 錯誤原因，或直接建構帶有關聯公式的財務模型。
安全雙重守則：(1) 授權寄信前務必親自審閱內文，因為寄件署名是你本人；(2) 僅在完全信任的試算表上啟用 Excel 外掛，防止陌生檔案隱藏惡意提示詞注入（Prompt Injection）。
高級（技巧 9 – 12）

瀏覽器自動化、離線排程、無程式碼開發與專業設計交付

9. Claude in Chrome 瀏覽器自動化操作

限付費方案 · 桌面版 Chrome [00:11:35]
核心能力：從 Chrome 線上應用程式商店安裝後，Claude 可直接讀取網頁、點擊按鈕、輸入文字、填寫表單，並在你指定的分頁群組間協同作業。
應用範例與進階功能：例如將包含 20 項新品規格的文件交給 Claude，自動逐一填入電商後台上架表單；支援將常用指令存為斜線捷徑（/）、透過時鐘圖示設定每日/每週自動執行網頁任務，或在經典版側邊欄錄製操作流程供 AI 重複執行。
隱私與安全防護：側邊面板預設為 Automatically approve 模式會連續執行操作。啟動前務必關閉網路銀行與私人敏感分頁；若需登入網站，建議搭配測試中的 1Password 整合功能，避免讓 Claude 直接接觸密碼明文。

10. Cowork 自主多步驟任務與 Computer Use（電腦操控）

Pro / Max 方案 · 桌面版 App [00:12:48]
無縫整合架構：Cowork 已不再需要手動切換獨立模式，系統會自動判斷你的指令是簡單問答還是複雜多步驟任務，並完整繼承你的 Memory、Projects、Skills 與 Connectors。
本機檔案與電腦操控：在桌面版 App 授權特定資料夾後，Claude 可直接讀寫與建立本機檔案（永久刪除前會先確認）。此外，可至 Settings → Capabilities 開啟測試版的 Enable computer use（支援 Mac 與 Windows），讓 Claude 操作電腦上的其他應用程式（系統預設封鎖股票交易與加密貨幣平台）。
安全提醒：Computer Use 目前無沙盒（Sandbox）隔離保護，使用前請先關閉所有私人敏感視窗。

11. 雲端排程任務（Scheduled Tasks）—— 關掉電腦也能自動執行

Pro / Max 方案 [00:13:57]
啟動方式：輸入斜線指令 /schedule 或點擊側邊欄的 Scheduled。任務完全在雲端運行，即使合上筆電、關閉電腦仍會準時執行，並可透過手機 App 隨時查看進度或回覆確認。
優質排程的四大要素：設定時必須明確定義：(1) 執行時間（如每週五下午 5 點）、(2) 資料來源（去哪裡抓本週發票）、(3) 處理動作、(4) 產出存放位置（彙整進哪張試算表）。
權限與測試建議 [00:14:30]：先手動執行一次並修正錯誤後再加入排程；權限模式建議維持在 Manual 或 Auto，僅對百分之百信任的成熟任務使用 Skip。

12. Claude Code 無程式碼工具開發與 Design / 辦公檔案生成

Code 限付費 · Design 與檔案生成全方案可用 [00:14:54]
Claude Code 打造專屬軟體（付費）：打開桌面版 App 切換至 Code 分頁，免開終端機、免安裝環境。選定資料夾後用自然語言描述需求（例如為副業打造客製化報價計算機），即可在內建瀏覽器預覽測試。
  • Plan Mode：大型專案務必先切換至 Plan mode 審核架構藍圖，確認後再允許修改檔案；附上參考介面截圖效果遠勝純文字描述。
  • 遠端接力：可將工作階段送往雲端持續運行，或輸入 /remote control 在手機端無縫接續開發。
Claude Design 與一鍵辦公文件輸出（全方案可用）[00:16:15]：
  • 互動式設計：透過對話要求設計或選擇 Output → Design，可產出可點擊的產品原型（Prototype）或網頁介面，支援匯出為 PDF、PowerPoint、Google Slides、HTML 或傳送至 Canva，亦能設定品牌設計系統（色票、字型、Logo），成熟後更可直接交給 Claude Code 轉化為正式產品。
  • 日常辦公檔案：開啟 Code execution and file creation 後，可直接生成可下載的 Excel、Word、PowerPoint 與 PDF（註：此功能專精於排版與文件，若需生成寫實照片請改用專用圖片生成工具）。
行動建議總結 [00:17:31]：如果今天只能做一件事，請先花 10 分鐘完成初級（技巧 1～4）的基礎設定。這四項基礎會直接放大後續所有中高級自動化功能的效果，幫你省下大量重複溝通與試錯的時間。
