楔子思過崖後洞

《笑傲江湖》裡我最喜歡的一段，不是任何一場決鬥，是華山思過崖後洞裡的那三天。

令狐沖被罰面壁，那時候他武功盡失、聲名狼藉，是華山派最沒有前途的一個弟子。一個自稱早已死掉的老頭從石壁後頭走出來，把獨孤九劍——那套源出於前代劍客獨孤求敗的劍法——一招一招傳給他。三日夜，傳完就走。

那老頭叫風清揚。

令狐沖要跪下拜師，他不受。理由簡單而硬：你已經有師父了。你是岳不群的弟子，這件事他不打算改，也不想沾。輩分上令狐沖只能喊他一聲太師叔——兩人之間，自始至終沒有師徒名分。他傳的是劍，不是門派；他要對方記住的是那套劍法，不是他這個人。

傳完之後他就消失了。後來令狐沖成名也好、闖禍也好、被逐出師門也好，風清揚一次都沒有出面替他撐腰，也沒有回來討過一句謝。

我十幾歲第一次讀，只覺得這老頭酷。過了六十歲再讀，讀出來的是另一件事：

一個已經退出江湖的人，
手上唯一還帶著的資產，
是一套沒有人接的劍法。

他不收徒，未必是清高。收徒要負責任、要排輩分、要接管門派恩怨、要對這個人的一輩子有個交代。他不要那些。他只要把劍傳出去——東西給你，名分免了。

我當然不敢自比風清揚。他是絕頂高手隱居，我是個工程師退休；他傳的是獨孤九劍，我傳的是幾萬行 MATLAB。但那個姿態我完全懂，而且我發現，人到了某個年紀、離開了某個位置之後，那幾乎是唯一還做得動、也還想做的一種傳授方式。

所以底下這篇文章，我從頭到尾管 Issa 叫徒兒，卻始終沒打算讓他喊我一聲師父。

壹兩個大拇指

七月二十二號下午兩點零六分，LinkedIn 跳出一則訊息，只有兩行法文：Bonjour。Comment allez-vous ?

發訊的人叫 Issa DEMBÉLÉ，頭像是個戴眼鏡的年輕人，站在一片綠色植物前面，穿白色繡花的傳統上衣，頭像外圈套著 LinkedIn 那個綠色的 #OPENTOWORK 圈。職銜欄寫著：Ingénieur d'État en Sciences Analytiques ｜ Data Science & Machine Learning industriel ｜ Chimiométrie ｜ Python ｜ R。

我隔了一天才回。而且我什麼字都沒打，只按了兩個大拇指的貼圖。

現在回頭看，那兩個大拇指是整件事情的入場券。我如果那天忙別的、或者手滑劃掉，這篇文章就不存在了。人到這個年紀會發現，人生裡多數重要的轉折，成本都低得離譜——當年決定接一通從加州打來的電話，也不過就是伸手把話筒拿起來而已。

七月三十號，他才把真正想說的話說完。他說他剛從摩洛哥畢業，主修分析科學、化學計量學與品質計量學；他讀了我的資歷，特別提到我在 Viavi 建預測模型生態系與近紅外光譜庫、以及在 NASA Ames 的化學感測研究；他說他剛起步，問我願不願意當他的 mentor——「哪怕只是非正式的，一個偶爾可以寫信請教的人」。最後他補一句：如果你有十五到二十分鐘可以講電話，我想聽你談這個領域要往哪裡去。

八月八號星期六晚上七點五十，我回了兩行：

「Sure.
I will.」

三個字，兩行。這就是我的收徒儀式。

貳「黑」字何解

題目我想了幾天。

中文裡的「黑」，第一義是沒有名分：黑戶、黑市、黑牌車，指的是不在編制內、沒有登記、查無此人的那種存在。Issa 不是我的研究生，不是我的部屬，不是任何機構指派給我的對象。我們之間沒有合約、沒有學分、沒有薪水、沒有智慧財產權條款，甚至沒有一張紙可以證明這件事發生過。他是我編制外的徒兒——一個黑徒兒。

當然，Issa 也確實是個非洲青年。我把這一層雙關留在題目裡，不是拿膚色當笑點，而是因為這兩層意思恰好指向同一件事：一個還沒有名分的人，去向一個已經沒有職位的人求教。他在編制外，我也在編制外。這門課從頭到尾都是黑的——沒有掛牌、沒有發票、查不到底。

我很喜歡這個狀態。做了一輩子有編號的事——專利有號、模型有版本、報告有文件代碼——臨老能有一件完全沒有編號的事，是奢侈。

他準備的四問

  3. 回看你自己的路，是哪些關鍵因素替你把門打開的？
  4. 人在美國以外，怎麼替自己卡進遠端的位置？

參拜師的門檻：你用不用 MATLAB？

八月十二號開會之前，他先寄了信，把四個問題整整齊齊列出來（見側欄）。我回信只問了一件事：

「你用不用 MATLAB？」

這問題聽起來像刁難，其實是誠實。我的功夫，九成住在數萬行 MATLAB 程式碼裡。去年開始往 Python 搬了一部分，但那個深度還遠遠追不上我原來那套。我告訴他：想深挖我的經驗，MATLAB 是前提；不想碰，我一樣可以給你高層次的判斷，那也是個很好的起點。

我沒有要他改宗。我只是把價目表攤開，讓他自己挑哪一層——反正兩層都不收錢。

而他履歷上寫的是 Python 和 R。這正是四十年的落差：我學會這行的時候，工具長那個樣子；他進來的時候，工具已經長這個樣子了。師徒之間真正要交接的，從來不是工具。

肆為什麼不收錢

田總問過我一樣的問題，語氣裡有一點好奇，也有一點看熱鬧：一個素不相識、在西非、跟你八竿子打不著的年輕人，你花時間教他，圖什麼？

我認真想過。理由有六個，一個比一個實際。

  1. 幾萬行程式碼需要第二個讀者

    我的 CMS 套件——分類的 CMS_Clsfrs、定量的 AQP 自動化管線——現在唯一的使用者是我自己。一套沒有第二個讀者的程式，跟一本孤本沒有兩樣：作者一下線，它就從「軟體」變成「遺物」。我退休以後每天還在寫、還在修，那不是為了交付給誰，是因為停不下來。但停不下來的東西，總得有人接得住。

  2. 我自己也是被人拉過一把的

    一九九八年五月我進 Cyrano Sciences 的時候，是個學高分子材料的人硬要去做演算法。真正把我領進化學計量學這一行的是 AJ。他寫的 idws 信心度演算法，我後來改成 idcn——徒弟把師父的東西改掉，是這個行業最高規格的謝禮。這筆帳我沒法還給 AJ 了。只能往下傳。

  3. 判斷力是唯一沒被專利收走的資產

    二十七、八個專利家族，署名是我，權利是公司的。四十年下來，真正完全屬於我自己、沒有任何一份文件能主張所有權的，只有一樣東西：判斷力——知道什麼時候該懷疑一條漂亮的曲線，知道哪個交叉驗證的分數是假的。這東西寫不進申請專利範圍，只能口傳。不傳，就跟著我一起銷帳。

  4. 退休者的時間，是唯一能送不能賣的東西

    時間這種資產很怪：不能儲蓄、不能變現、不能繼承，卻可以整批送人。上班的時候我的時間是別人的成本，所以有價；退休以後它沒有市價了——沒有市價，不等於沒有價值，只是說，它的價值只能靠送出去才會顯現。

  5. 教，是最誠實的復盤

    我這兩年在寫《老熊隨筆》，發明了一個說法叫「復盤體」：敘事歸敘事，考據歸考據。但寫作是對著紙復盤，紙不會反問你。教學是對著人復盤，而人會反問。他問我「這個領域怎麼變的」，我才被迫把二〇〇一年的 SIMCA、PLS-DA、LDA、CDA 一路排到今天的 SVM 與隨機森林，並且必須誠實承認：為什麼 SVR 始終沒有取代 PLS，我到現在也講不出一個真正說得通的理由。這種「我不知道」，只有在有人坐在對面的時候才會浮出來。

  6. AI 教得了方法，教不了「哪些路不要走」

    我現在每天跟 AI 一起寫程式，很清楚它有多強。它能把方法講得比我清楚、比我快、比我有耐心。但它拿不到一樣東西：負面知識——我踩過的坑、選錯的方法、白做的那兩年。沒有人會把失敗寫成論文，所以沒有語料。這種知識只能從一個活過的人嘴裡出來，而且通常是不小心說出來的。

上班的時候，經驗是資產，要留一手；
退休以後，經驗是庫存，不出清就報廢。

伍一九九八與二〇二六：兩個外地人

他的第四個問題——「人在美國以外，怎麼替自己卡進遠端的位置」——我特別想答。因為一九九八年的我，問的是同一題的南方版本。

那時候我人在路易斯安那，做的是高分子材料，想做的是演算法；機會全部在加州，而我在拉法葉。那一年前後我跑了四場面試，每一場都在解釋同一件事：為什麼一個材料背景的人，應該被放去做分類演算法。我當時最需要的不是履歷指導，是有人肯接我的電話。

二十八年後，一個在摩洛哥受訓的馬利工程師，隔著十一個時區問我同一件事。我沒有辦法替他辦簽證，沒有辦法給他職位——我連自己的職位都沒有了。我能給的，剛好就是當年別人給我的那個東西：把電話接起來。

柒第一問：這一行是怎麼變過來的

她說得沒錯。以下是我那天準備的內容——她要是全程聽完，大概會把「比較多」改成「多很多」。

他的第一問是：化學計量學從你入行到現在怎麼變的，又要往哪裡去。我的答覆是這樣寫的。

我真正踏進化學計量學大約在二〇〇一年前後，地點是帕沙第納的 Cyrano Sciences——一家做化學感測器、也就是俗稱「電子鼻」的公司。那個年代這一行的主旋律，我會給它一個名字：線性化學計量學。

分類這一端，檯面上被反覆討論的就是那幾樣：SIMCA、PLS-DA、LDA、CDA。定量那一端，PLS 是主力——而且說實話，到今天大致還是。非線性的替代方案，例如 SVR，始終沒能真正流行起來；為什麼會這樣，我到現在也講不出一個能說服自己的理由。

這句話我特意保留在給他的答覆裡。一個做了二十幾年的人，最值得年輕人聽的往往不是他懂的部分，而是他承認自己不懂、卻又確實觀察到的那塊空白。那是還沒有人去填的位置——說不定就是他的位置。

這二十幾年，我親眼看著非線性方法一步一步走進來：支援向量機（Support Vector Machine／SVM）、隨機森林（Random Forest），以及其他。我認為這個趨勢會繼續下去。理由一點都不玄：

真實世界的資料很少是線性的。
一個類別往往不只一個質心。

同一個類別經常是多峰的——同一種樣品，可能因為產地、批次、儀器、季節而在特徵空間裡散成好幾團。資料一旦複雜到那個程度，非線性方法幾乎是唯一的出路。這不是趕時髦，是被資料逼的。

我也告訴他，我不是旁觀這個轉變的人。當年在 Cyrano，把 SVM 推進分類流程的就是我。所以我談這件事的時候，帶著一點當事人的偏見——這一點我也一併告訴他了。

定量PLS（主力）PLS 仍是主力；SVR 始終未成氣候（原因待解）
假設類別單一質心、關係近似線性類別多峰、多質心、關係非線性

捌第二問：現在該練什麼

第二問是：一個資淺的化學計量學家，現在該把力氣放在哪裡。

我沒有給他一張演算法清單。我給他看一張圖。

圖一　預測模型的生態系外圈四個環節：Models Building、Models Optimization、Models Transfer、Models Updating，彼此以綠色的 Automated Pipeline 首尾相接；正中央的紅色橢圓是 Models Diagnosis，四支紅箭分別指向外圈的每一個環節。左上角那行藍字是我加的：最重要的一環是診斷，為的是不要落入黑箱。

這張圖的重點不在圈上那四個方塊——那四件事任何一本教科書都會講。重點在圓心。

模型診斷不是建模做完之後的一道驗收手續，它是唯一同時連到四個環節的東西：你在建模的時候要診斷，在調參的時候要診斷，把模型從一台儀器搬到另一台儀器（model transfer）的時候更要診斷，模型上線之後隨時間更新還是要診斷。四支紅箭是雙向的意思——每一個環節都要能被拆開來看，也都要能把看到的東西送回圓心。

我這輩子看過太多漂亮的準確率，事後才發現是資料洩漏、是分群切錯、是驗證集其實跟訓練集來自同一批樣品。一個你無法診斷的模型，準確率再高也只是一個運氣不明的黑箱。而黑箱在實驗室裡叫成果，在產線上叫事故。

所以我給他的答案濃縮成兩句：

一、建立一個以「模型診斷」為核心的生態系——診斷的具體手段，是把建模生命週期的每一個階段都畫出來。
二、把它自動化成管線。

圖上綠色的那四支箭寫的都是同一個詞：Automated Pipeline。手工做一次叫實驗，自動做一千次才叫工程。這是我認為他這個階段最該投資的東西——不是再多學三種分類器，而是把「跑一次完整流程」的成本壓到接近零。

然後我給他看我自己的兩套實作。不是樣板，是我每天在用的東西。

圖二　CMS_Clsfrs：分類端一個視窗，幾個下拉選單。Pick_DS 選資料集；PPn 選前處理（截圖上停在 1stDerSGFL7[PO2]+SNV，也就是七點 Savitzky–Golay 一階導數再加 SNV）；asmc 與 ScanThru 管自動掃描；Clsfr 選分類器（此處為 SVM_Linear_wDVs_APs，帶決策值與後驗機率的線性支援向量機）；HyPara 選超參數組。按下 Predict，左下吐出 Accuracy(%)，中間吐出 NmisP（誤判數）；而右邊那個 PLOT 下拉，才是整個介面真正的核心。

這個介面很土。我知道它很土——灰底、藍字、螢光綠的百分比，是上個世紀的審美。但它做到一件事：把「換一個前處理、換一個分類器、換一組超參數」的成本壓到三次點擊。

試一次的成本夠低，人才會誠實。成本一高，人就會替第一次跑出來的漂亮數字找理由，因為重跑太麻煩了。自動化真正的產物不是效率，是誠實。這句話我想他二十幾歲聽不太進去，四十歲會想起來。

而 PLOT 那個下拉選單，就是圖一的圓心落地的地方：每一個階段——前處理後的光譜、投影後的分佈、決策值、信心度、誤判樣本落在哪裡——都畫得出來。畫得出來，才叫診斷得了。

圖三　AQP：定量端的函式相依圖AQP＝Automated Quantitative data analytic Pipeline（自動化定量分析管線）。這是 AQP_gui.m 的相依關係圖：左下角是進入點 AQP_gui，往外牽出數百個節點——PLS_inside_PLS_predict、SVR_PLS_Opm_by_Testset、GLSstd_ApplyOn_UDM、Match_wvl_HiRes2LoRes、XLSX2MAT⋯⋯每一條線是一次呼叫。

這張圖看起來像一團亂麻。它確實是一團亂麻——而那正是我要他看的東西。

我讓他看它，不是為了炫耀行數。是要他先有一個心理準備：一個真正能用的自動化管線，長期而言就會長成這副樣子。它不是設計出來的，是二十幾年一層一層長出來的；每多一台儀器、每多一種樣品、每一次「這個 case 為什麼不行」，就多長幾條線出來。沒有人能從白紙上一次畫對這張圖。

但這團亂麻與一個大黑箱之間，只差一件事：你能不能在其中任何一個節點上停下來，把那一步畫出來看。能，它就是生態系；不能，它就是你自己都不敢動的遺產。

這也正好回到我前面說的，為什麼我需要第二個讀者。這張圖裡沒有任何一條線是別人畫得出來的——每一條都對應一個具體的、當年非解不可的問題。而那些問題，只有我還記得。

玖螢幕亮起來

八月十二號，Google Meet 的視窗跳出來。西非那頭是傍晚，紅木海岸這頭是早上。

第三問（哪些因素替我打開了門）和第四問（人在美國以外怎麼卡進遠端的位置），我到開會那天都還沒寫成稿。這兩題不好答，因為誠實的版本是：有一半是運氣，而運氣的另一個名字，叫有人肯接你的電話。

所以那兩題我打算用講的。講完之後，我大概還會多花二十分鐘講我踩過的坑——那些沒有人會寫成論文的東西，因為沒有人會發表自己的失敗。這才是他從我這裡唯一拿不到第二份的貨。

沒有學費，沒有合約，沒有名分。一個編制外的老頭，一個編制外的徒兒。這門課，從頭到尾都是黑的。

—— 老熊，寫於開課當天早晨
