一那句話的出處

昨天夜裡（2026年9月27日），我整理了一篇《老熊與電腦系的前世今生》。起因是一次LINE群組閒聊，牽出1976年的大學聯考：我離電機不到一分，又是早讀一年，一個從來不喜歡化學的人就這樣被分進了化工系。文章最後，我把這半生寫成了「扳回一局」。

今天拿一句流傳很廣的話，把它重讀一遍：

世間所有的相遇，都是久別重逢。

復盤體的規矩，先查出處。這句話在網上流傳極廣，常被安在張愛玲名下，也有人說出自王家衛的電影《一代宗師》，或是白落梅的散文。幾種說法各有人引，卻很少有人拿得出原文段落。它本身就是一則值得復盤的「集體記憶」：人人都記得，沒人查證過。

出處說不清，不妨礙它好用。這句話換掉的是框架：「扳回一局」是一張記分牌，有輸有贏；「久別重逢」講的是相認，只問你認不認得出對方。換這副眼鏡重讀，昨天那篇文章的主線就不再是一場輸贏，而是一次重逢。

二與電腦的重逢：不是錯過，是暫別

這是全文的主線。

1976年我離電機不到一分。照「扳回一局」的讀法，那是一次錯過。可是把證據攤開來看，「錯過」兩個字站不住：

證據說明
偏好從來就不喜歡化學。這不是事後補的說法，當年填志願的行為就能作證
填法台大只照前一年的排名抄了三個，後面的志願刻意避開化學相關科系
結果化工是那張排名表分配給我的，不是我選的

換句話說，1976年那一刻，我本來就站在電機、電腦那一邊。那不到一分的差距，與其說是錯過，不如說是暫別。

後來的路是化工、高分子、Akron博士、博士後，然後轉進化學計量學。進了化學計量學，我挑的偏偏是數學和演算法那一半：多變量校正、支援向量機（Support Vector Machine／SVM）分類、MATLAB演算法開發。2013年，我又進了 Apple。

這幾步回頭看都不像初次見面，倒像在人群裡認出一個老熟人：咦，這不是當年那個嗎？

三不是扳回，是本來沒離開

昨天那篇的結尾是這麼寫的：

填錯的志願，最後被自己改回了原本的方向。——《老熊與電腦系的前世今生》

這句已經很接近了，只差一步。

「扳回一局」是輸贏的框架：1976年輸了一局，後來贏了回來。可是文章自己的證據，撐不起那個「輸」字。一個人被分到不喜歡的系，偏好卻從頭到尾沒變，他其實沒輸掉什麼，只是和原本的方向分開走了一段路。

所以不是「改回」，而是本來就沒離開。

填錯的志願，沒有改變我要去的方向；
它只讓我繞了一段路，
才和原本的方向重逢。

四那條路，親自走過來

從「久別重逢」的角度看，昨天那篇寫得最單薄、卻最有重逢味道的一筆，只有一行：30歲那年，我娶了上海交大計算機系的田總。

那一行被我當成收尾的笑點。Claude 點評時追問了兩個問題，答案補在這裡。

Claude
你們認識的時候，她在做什麼？
老熊
她在同校讀電機／電腦碩士。

她是1982年高考上海考區第五名，進了上海交大計算機系，1986年畢業。我在台灣差不到一分沒進電機；她在上海以考區前五的成績走進計算機。兩條路在海峽兩岸各自出發，後來在美國同一所學校交會：我讀高分子博士，她讀電機／電腦碩士。

Claude
你後來轉向演算法、進 Apple，跟家裡有一位計算機出身的人有沒有關係？
老熊
有關係，尤其在編程時 tool chain set up 方面，她的點撥居功至偉。

這個答案很工程師，也很真實。寫過程式的人都知道，最先擋住人的往往不是演算法本身，而是 tool chain：編譯器、函式庫、環境設定、路徑，那些沒人教、書上也寫得含糊的東西。卡在這一關，再好的想法也跑不起來。一個從高分子半路轉過來的人，最容易卡的正是這一塊，而家裡剛好有一位科班出身的人在旁邊點撥。

如果電腦是我1976年錯過的那條路，
田總就是那條路親自走過來找我。

這一段補上，故事就從「分數與排名」變成了「人與人」。而久別重逢，說的本來就是人。
